## 0. Leo 的话

- 同一个嵌入式柱子或冰箱型号，让客人选不锈钢还是可装门板（门是柜子颜色）。
- 实际出厂默认是可装门板的。例如 T18IF905SP-SS 是不锈钢，T18IF905SP 是可装门板，尺寸一样。
- 计划要写：
  - 目录数据怎么记（从他的表格导入；现在"颜色"空着就默认成不锈钢）；
  - 界面上在哪里选，可装门板时门怎么画；
  - 报价单上型号和价格怎么显示；
  - 列出要他答的现场问题。

## 2. 目录数据怎么记（只列，不选）

| | 做法 | 表格里怎么填 | 页面里 |
|---|---|---|---|
| 甲 | **两行，两个型号**：T18IF905SP（可装门板）和 T18IF905SP-SS（不锈钢）各一行 | 每个有两种版本的型号多填一行，"颜色"填 `SS` 或 `Panel Ready`，价格各填各的 | 卡片上两个当成两个型号，客人换型号就是换面板。链接、配置单都不用改 |
| 乙 | **一行，两种面板**：一行里"颜色"填两种（例如 `SS / Panel Ready`），另加一列不锈钢版的价格（或差价） | 每个型号一行，多一列 | 卡片上同一个型号下面加一个"不锈钢 / 可装门板"的选择；页面要记住每个格子选的面板；链接加一项；配置单按选的面板写型号和价格 |
| 丙 | **一行可装门板 + 钢门板当配件**：机器只记可装门板版本，不锈钢 = 可装门板机器 + 厂家的钢门板（像 18" 酒柜现在的 TFL18IW105） | 机器一行，钢门板另起几行（每种宽度、有无把手） | 卡片上选"用柜门 / 用厂家钢门板"；配置单多一行门板 |

不管选哪种，导入规则"颜色空着默认不锈钢"都要改：
- 改成默认可装门板（照 Leo 说的"出厂默认是可装门板"）；或者
- 空着就报出来让人补，像第 92 轮那样手填的格子空着就停下来。

只改冰箱柱子这一类，还是整个目录（洗碗机、油烟机也有空着的），要 Leo 定。

## 3. 界面上在哪里选，门怎么画

- **在哪里选**：
  - 甲：不用新地方，就在型号卡片的型号列表里，两种版本各一项；
  - 乙、丙：在型号卡片（`ModelCard.tsx`）选中的那台下面加一个两项的开关。手机和电脑是同一个卡片。说明卡（`SpecCard`）上写出现在是哪一种。
  - 开关上的字要 Leo 给（例如「不锈钢 / 可装门板」）。
- **门怎么画**：可装门板时照现在的画法，门穿这排柜子的门色；点缀色那一排（D15）上的就穿点缀色。不锈钢照现在。
- **柱子之间、柱子和柜子之间的板，不跟着变**。

## 7. 要 Leo 答的现场问题

1. **两种版本价格一样吗？** 不一样的话差多少，还是各有各的价？
2. **哪些型号两种都有？** 只有 SP 柱子（T18IF900SP、T18IW905SP、T24IF905SP、T24IR905SP、T24IW905SP、T30IR905SP、T18IW100SP）？T36BT120NS / T36IT100NP 这一对算不算同一个型号的两种版本（尺寸和型号都不同）？
3. **表格里怎么记最省事？** 第 2 节甲（两行）、乙（一行两列价格）、丙（机器一行 + 钢门板配件）。
4. **报价上型号带不带 `-SS`？**
5. **默认**：各套餐打开时，这些柱子是可装门板（照出厂）还是不锈钢（照现在）？默认一变，A–E 的画面都会变。
6. **"颜色"空着时**：默认可装门板，还是要求一定填？只管柱子，还是整个目录？
7. **可装门板时**，清单里要不要一句"门板由柜子厂按柜门做"？
8. 18" 酒柜现在的"订厂家钢门板（TFL18IW105 / TFL18IW10R）"那一条，和 `-SS` 整机是什么关系：`-SS` 是不是就是"可装门板机器 + 厂家钢门板"出厂装好？
