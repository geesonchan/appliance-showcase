## 2. 改法

### 2.1 段宽和尽头（`layoutTemplate.ts`）

- `fridgeSegmentIn` 嵌入式一支改成：机器宽 + 尽头那一块。冰箱外侧是墙时 3-1/2"，否则 3/4"，靠台面那一侧 0。所以 A 从 42" 变成 **36-3/4"**（外侧「柜体」）或 **39-1/2"**（外侧「墙身」）。
- `single` 嵌入式分支：模块是 `T3696`（带 `insetIn: 0`，`cabinets.ts` 就不画两块 3" 板）加尽头一块：
  - 墙：`BF3.5`，`filler`，与独立式靠墙时同一个词「靠墙填充板」；
  - 柜体：`PNL0.75`，`panel`。
- 一字型由 `fromTheWall` 自动倒过来，变成 `BF3.5 T3696`。
- `openingIn` 只给冰箱以外的东西用，嵌入式冰箱不再加 `PANEL_IN * 2`。`PANEL_IN` 本身不删：B 的柜组（`bank()`，`:1876`）、独立式规则 11 和别处还用它。
- `fridgeOpeningOf`：单台嵌入式的开口取 `tall` 模块自己的范围，不再用 `insetOf` 往里缩；柜组照旧，保证 B/D/E 一个字节不变。
- `cabinets.ts`：
  - `tall` 模块 `insetIn: 0` 时不画 `-panel-a/-panel-b`（代码已经这样走）；
  - `PNL0.75` 和 `BF3.5` 走已有的「tall 段里的 panel/filler」分支（`:298-313`），落地到 96" 并叠到 108"；
  - `endOnTheFloor` 改读最后一块板的宽（0.75 或 3.5），不再假设 3"。
- **要 Leo 定的**：问题 1–6。
