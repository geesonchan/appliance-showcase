## 2. 做法（只列，不选）

### 2.1 查不到名字时退回什么

| | 退回的名字 | 要的新词 | 说明 |
|---|---|---|---|
| 甲 | 格子自己的名字（`slot.oven` 这一类，标注上用的那个词） | 不用新词 | 清单上会出现标注用的词，比如「烤箱」，而不是清单里的「烤箱塔」。和"同一个东西只用一个词"有冲突的可能 |
| 乙 | 一个通用的词，例如「电器」/ "appliance" | **要 Leo 给中英文** | 名字不准，但不会错指 |
| 丙 | 不显示名字，只显示宽度和编号（清单本来就有 `item.code`） | 不用新词 | 鼠标停上去的说明变空 |

不管选哪种，都要保留"漏词测试会红"：
- 做法一：页面用退回版本，测试用严格版本。例如 `billLabelKey` 加一个参数，或者另写一个严格的函数给测试用。
- 做法二：退回时打一行 `console.error`，浏览器测试遇到这行就算红。

### 2.2 出错隔离放在哪里

Leo 说的是"右侧面板和 3D 画面各加一道"。代码上的位置：
- **右侧面板**：`App.tsx` 里 `<RightPanel />` 外面一层；手机抽屉里的 `<RightPanel tabs={false} />` 外面也要一层（`MobileSheet.tsx:164`），不然手机上照样白屏。
- **3D 画面**：`Scene.tsx` 的 `<Canvas>` 外面一层。
  - `@react-three/fiber`（8.17）会把画布里面组件渲染时的报错交给画布外面的隔离去接。
  - 但每一帧里（`useFrame`）出的错不是渲染时的报错，接不住。要不要另外处理，要先试。

**没在 Leo 的单子里、但同样会整页白屏的地方**（列出来，由 Leo 定要不要也加）：
- 左侧面板（手机抽屉里也有）；
- 画面上的标注、卡片、提示（在 `<Canvas>` 外面，`App.tsx` 的 `main` 里）；
- 顶栏；
- 配置单页。

**出错后显示什么**：
- 那一块的地方显示一句提示，页面其余照常。**提示的中英文要 Leo 给**。
- 要不要"重试"按钮（重新挂载那一块），还是只提示刷新页面？
- 换套餐或重建房间时，要不要自动重试（隔离用 `layoutVersion` 当 key）？

**出错时要不要记下来**：
- 线上的访问计数（GoatCounter，D24）能记事件。要不要记一个"某一块出错"的事件？这会动到 D24 定的"只记四种事件"，要 Leo 定。

### 2.3 怎么"故意让一块出错"来测

测试跑的是构建好的页面（`tests/globalSetup.ts` 起 `dist` 的预览）。要让一块故意出错，有几种办法：

| | 办法 | 线上会不会带着它 |
|---|---|---|
| A | 构建时加一个只给测试用的开关（例如 `VITE_FAULTS=1`），页面读链接参数 `?fault=panel` / `?fault=scene`，让那一块渲染时报错 | 不带开关构建时，这段代码被构建工具整个删掉，线上文件不变。但测试要用带开关的构建，和线上构建不同 |
| B | 不加开关，用浏览器测试拦截某个请求，或往页面里注入坏数据（例如改分享链接里的型号），让真实代码报错 | 线上什么都不用加；但要找一条真实会报错的路径，退回名字做好以后这条路径可能就不报错了 |
| C | 只在单元测试里测隔离组件本身（项目现在没有 jsdom / React Testing Library，要新加） | 不碰页面，但证明不了"页面不白屏" |

测试要证明的：一块出错时，
1. 其余部分还在：画布在、顶栏的按钮能点、另一侧的面板能用；
2. 出错那一块显示提示；
3. 白屏那条路径（99b 的测试，三种宽度、两种形状）照样绿。

## 3. 怎么证明（照 D17）

- 新测试先在旧代码上跑红：故意出错时整页白屏。

## 4. 影响范围

- 所有套餐、两种形状、三种宽度。没出错时，画面和文字都不该变。
- 只在出错时行为不同：从整页白屏，变成一块显示提示。
