## 1. 每一帧里的报错

### 现在

- 第 99c 轮试过一次：每一帧里报错，页面不白，面板、顶栏、套餐按钮都能用；但 3D 画面停在空白，报错每一帧重复（约 8 秒 485 次），隔离接不住，也没有提示。
- **为什么接不住**：
  - fiber 的帧循环 `render$1`（`node_modules/@react-three/fiber/dist/events-776716bd.esm.js:1530-1543`）逐个调用每个 `useFrame` 的回调，**没有 try/catch**；
  - 报错从浏览器的 `requestAnimationFrame` 里抛出去，不经过 React 的渲染。
  - 而 React 的隔离（包括 99c 的 `PartFence`，以及 fiber 画布里自己那一道）只接得住**渲染时**的报错。
- 用到 `useFrame` 的地方一共 6 处，都在 `src/three`，没有别的库（项目没用 drei）：

| 文件 | 行 |
|---|---|
| `CameraRig.tsx` | 251 |
| `DimensionProjector.tsx` | 58 |
| `ModuleLabelProjector.tsx` | 35 |
| `OcclusionFade.tsx` | 253 |
| `PinProjector.tsx` | 119 |
| `QualityGuard.tsx` | 33 |

### 做法

把"帧里的报错"变成"渲染时的报错"，让它走 99c 那条现成的路：
1. 新写一个 `useSceneFrame(callback)`（放在 `src/three/`），6 处都改用它，不再直接用 fiber 的 `useFrame`。
   - 它在里面调 fiber 的 `useFrame`，把回调包在 try/catch 里；
   - 接到报错，就记在一个只属于画布的地方。
2. 画布里放一个小组件（`Scene.tsx`）。看到记下的报错，它就在**下一次渲染时把这个报错抛出来**。
   - fiber 自己那道隔离接住，交给画布，画布再抛到外面；
   - 99c 的 3D 画面隔离接住：显示 Leo 的那句话和「重试」，访问计数记 `appliance-showcase/part-failed-scene`（一页一次）。
   - 画布卸下，帧循环随之停止，不再每帧重复报错。
3. 「重试」和换套餐照 99c：把 3D 画面重新装上。
4. **守住"只走这一处"**：加一条单元测试，查 `src` 里除了 `useSceneFrame` 自己，没有别的文件直接从 `@react-three/fiber` 引 `useFrame`。照 `analytics.test.ts` "每个事件只在一处记"的写法。

### 测试开关

`?fault=scene-frame`：画布里一个 `useSceneFrame` 回调每一帧报错，直到重试，做法照 99c 的 `fault.ts`。访问计数里仍记作 `scene` 那一块（Leo 定的是"哪一块出错"，不是怎么出错的）。

### 测试怎么先红后绿

- `tests/partFence.test.ts` 加两条：电脑用鼠标、手机用手指，各一条。
  - `?fault=scene-frame` 开页后，3D 画面的位置显示那句话和「重试」，其余照常；
  - 按重试，画布回来，而且**在画**：渲染次数在涨，不是停在 99c 试验里那个 34。
- **先红**：只加开关和 6 处的 `useSceneFrame`（它先只是原样转给 `useFrame`），不加"记下再抛"。这时测试红：画面空、没有提示，和 99c 试验看到的一样。
- **再绿**：加上"记下再抛"。
- "只走这一处"那条单元测试：在旧代码上红（6 处都直接用 `useFrame`）。

## 2. 链接提示太长

### 现在

- 打开链接时，链接里没给或用不上的每一项，提示里列一行（`SceneControls.tsx` 的 `ShareNotice`，约 243–255 行；行由 `openLink.ts` 生成）。
- `?v=2&pkg=A` 这样几乎什么都缺的链接，列三十多行，盖住整个 3D 画面（99c 预览里看到的）。

### 做法

- 提示的行数 **3 行以内**：照现在一行行列。
- **超过 3 行**：只显示一句「这个链接不完整，缺了 N 项，已按默认显示。」，加一个「详情」按钮，点开后照现在一行行列出全部。
- 新词放进 `en.json`、`zh.json`，锁进 `reviewed.json`：
  - 那句话：Leo 的中英文原话，N 用 `{count}` 代入；
  - 按钮的中文「详情」：Leo 的原话；
  - 按钮的英文：**Leo 没给**，见第 4 节问题 1。
- 提示原来的「关闭」照旧。

### 测试怎么先红后绿

- `tests/shareLinkCut.test.ts` 的 63 条照样全绿。每条只拿掉一项，所以都在 3 行以内，照旧一行行列，原来的判断不用改。
- 新加：
  1. `?v=2&pkg=A`（缺二十多项）：页面不白，提示里只有一句话，N 等于实际缺的项数，看不到逐行的内容；按「详情」后全部列出，每一项的名字都在里面。
  2. 正好 3 项：照旧一行行列。
  3. 4 项：只显示一句话。
- **先红**：在 `cb4222c` 上，第 1、3 条红（现在是全部列出），第 2 条绿。
