## 一、现在是什么样

- B 和 E 的组合烤箱塔，没有自己的"烤箱离地高度"滑杆，是**微波把手高度**那根滑杆在定高度：44″ 到 60″，每格 1″，默认 54″。
  - 切口底离地 = 把手 − 39″，最高 18″，所以 57″ 以上都是 18″（`src/data/columnModel.ts` 的 `comboSillFor`）。
  - 烤箱下面那个柜子（下面叫"抽屉箱"）= 切口底 − 4″ 踢脚。
- 页面只给高过 6″ 的柜子画面（`src/three/CabinetLayer.tsx` 的 `hasDoor`）。12b 只给 D 的那座塔开了例外（`src/data/cabinets.ts` 的 `isDoubleOvenTower` 和 `underOvenFront`）。
- 所以现在：
  - 把手 44″–49″：抽屉箱 1″–6″，**光柜体，没有面**；
  - 把手 50″–60″：抽屉箱 7″–14″，一块柜面。
- **一处登记时没写到的**：D 在一字型时，那座塔（MEM301WS）也挂在同一根微波把手滑杆上。它不算 12b 的"双门烤箱塔"，所以和 B、E 一样，44″–49″ 也是光柜体。是读代码、再在页面上拍出来确认的（见第三节的图）。

## 二、D 的规矩照搬过来，每一格会变成什么

D 定下来的规矩（12b，你的答复 A、B）：

- 抽屉箱不到 6″：固定面板；
- 6″ 到不到 12″：一个抽屉；
- 12″ 起：两个一样高的抽屉。

照搬到 B、E（和一字型的 D）以后，每一格是这样：

- 把手 44″：切口底 5″，抽屉箱 1″。现在光柜体 → 固定面板 1″。**会变**
- 把手 45″：切口底 6″，抽屉箱 2″。现在光柜体 → 固定面板 2″。**会变**
- 把手 46″：切口底 7″，抽屉箱 3″。现在光柜体 → 固定面板 3″。**会变**
- 把手 47″：切口底 8″，抽屉箱 4″。现在光柜体 → 固定面板 4″。**会变**
- 把手 48″：切口底 9″，抽屉箱 5″。现在光柜体 → 固定面板 5″。**会变**
- 把手 49″：切口底 10″，抽屉箱 6″。现在光柜体 → 一个抽屉 6″。**会变**
- 把手 50″：切口底 11″，抽屉箱 7″。现在一块柜面 → 一个抽屉 7″。不变
- 把手 51″：切口底 12″，抽屉箱 8″。现在一块柜面 → 一个抽屉 8″。不变
- 把手 52″：切口底 13″，抽屉箱 9″。现在一块柜面 → 一个抽屉 9″。不变
- 把手 53″：切口底 14″，抽屉箱 10″。现在一块柜面 → 一个抽屉 10″。不变
- 把手 54″（默认）：切口底 15″，抽屉箱 11″。现在一块柜面 → 一个抽屉 11″。不变
- 把手 55″：切口底 16″，抽屉箱 12″。现在一块柜面 → 两个抽屉 6″+6″。**会变**
- 把手 56″：切口底 17″，抽屉箱 13″。现在一块柜面 → 两个抽屉 6-1/2″+6-1/2″。**会变**
- 把手 57″–60″：切口底 18″，抽屉箱 14″。现在一块柜面 → 两个抽屉 7″+7″。**会变**

合起来：

- **会变的**：把手 44″–49″（光柜体有了面）和 55″–60″（一块变两块）。
- **不变的**：50″–54″，默认的 54″ 也在里面。
  - 原型里这五格和现在的版本一个像素都不差（下一节），说明照搬后"一个抽屉"的画法和现在的"一块柜面"完全一样。
