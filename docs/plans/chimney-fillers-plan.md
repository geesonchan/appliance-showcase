## 2. 照 Leo 的方向，做出来是什么样

- 油烟机两边各一块填充板，宽度补满差值：(36 − 29-15/16) ÷ 2 = **3-1/32"**。
- 和旁边吊柜同深（12"）、同底（54"）、正面齐平，是那段吊柜的一部分。
- 到 96" 为止是板本身。按 D19 现有的规则，停在 96" 的每个柜子上面都叠一个 12" 的叠柜；窄于 9" 的不算柜子，是"同一块板往上接"（`stackOn`，`src/data/cabinets.ts:562`，编号 `PNL…X12`）。所以不用另写，板会自己接到 108"，冠线沿那段吊柜的顶走，盖过板。
- 两块板之间照旧敞着：54" 到罩体底（A、B、D 是 66-1/2"），以及罩体以上、13-3/16" 宽的烟囱罩两侧，一直到天花。这是油烟机自己的地方，草稿不动。
- 只在差值大于 1/2"（`SCRIBE_IN`）时才加板。HMCB36WS 和 C 自带的 HMCB30WS 两边只差 1/32"，不加。

## 4. 「进配置单」——要 Leo 先答

**现在的配置单不列任何柜子。** 页面上叫「配置单」的是 Quote 打开的那一页（`quote.title`，`src/ui/QuotePage.tsx`），它一行一台机器：型号、开口、管线、价格（`QuotePage.tsx:218` 注释写的是「One appliance」）。墙长滑杆下面那份清单（`wallRequirement`，`layoutTemplate.ts:2377`）列的是一面墙上落地的机器和柜段，也不列吊柜。

所以「当作柜体进配置单」有几种读法，**只列，不选**：

1. 配置单另起一节「柜体」，只列这两块填充板（尺寸、位置）。
2. 配置单另起一节「柜体」，把整间厨房的柜子都列进去（这就是一份柜体清单，比这一条大得多，应该是单独一轮）。
3. 不进 Quote 那页；只在墙长下面的清单里加一行（那份清单现在只管落地的东西，加吊柜也是新规矩）。
4. 只在 3D 里画成柜体（有叠板、有冠线），不进任何清单。
