## 4. 型号怎么带（Leo 的规则）

**规则**：
- 两种形状里**开口不同**的位置，各记各的。
- **开口一样**的位置，共用一个选择，在哪个形状里换都算数。

**"开口不同"按什么算**：按套餐在 `shapes.one-wall` 里有没有改写这个位置，而且改写的是开口本身：宽、类别、安装方式、高、深。只改了位置或镜头的不算（`beside`、`bestView`）。按这个算：

| 套餐 | 各记各的 | 共用 |
|---|---|---|
| A、B、C | 无 | 全部 |
| D | 冷冻柱、冷藏柱、酒柜柱（宽度变了）、烤箱（换成组合烤箱开口） | 灶台、烟机、洗碗机；一字型省掉的咖啡机、第二台洗碗机、微波抽屉只在 L 型里有 |
| E | 烟机（42" 岛台式 → 36" 墙挂烟囱式） | 冷冻柱、冷藏柱、组合烤箱塔、咖啡机、咖啡机下的酒柜、洗碗机，**以及电磁灶** |

**请 Leo 确认 E 的电磁灶**：它的开口（36" 嵌入式）两种形状一样，只是从岛台搬到墙上、下面的柜子不同。按上面的算法它算"共用"，你列的"灶"是"各记各的"。我按哪个做，请你定。

**怎么做**：
- 页面记住每个套餐在每种形状里、各记各的那些位置上选的型号。共用位置只有一个选择。
- 换形状时：
  - 各记各的位置，取目标形状里记下的型号，没记过就用目标形状的默认；
  - 共用位置带着当前的选择走。
- 切回 L 型时，房间（墙长等）仍然恢复切换前存下的那个；型号改成按上面的规则，不再把整份 L 型的选择照快照放回。
- 换套餐时，照现在 L 型里换套餐的规矩（放得进就带）。

**测试**（已登记的两个，加上两个）：
- 在一字型换洗碗机，切回 L 型后仍是新换的那台。
- 在一字型换烟机，切回 L 型后仍是 L 型原来的那台。
- 在 L 型换 D 的冷冻柱，进一字型后是一字型默认的 18" 那台，切回 L 型后是 L 型里换的那台。
- 在一字型换 D 的 18" 冷冻柱，回 L 再进一字型，仍是一字型里换的那台。

**分享链接的格式不变**：仍是 `v=2`，字段也不变。链接只记"现在看到的房间"（D23）：当前形状、当前形状下每个开口的型号。另一种形状里记下的型号不进链接，打开链接的人看到的就是发链接的人看到的。

**怎么证明旧的 v=2 链接打开完全一样**：
- 用 98b-1 的代码（`e61bb58`）写出五个套餐的 L 型链接和五个一字型链接，连同打开后房间的指纹（和 `shareLink.round97.json` 同一种算法：参数、柜列、机器位置、岛台、柜体的 sha256），存成 `shareLink.round98b1.json`。
- 98b-2 的代码打开这十个链接，指纹必须一样，而且不出提示。
- `v=1` 的五个旧链接照旧（`shareLinkV2.test.ts`）。
